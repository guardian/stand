# Table

Table is a composable, responsive data-table built on [React Aria Table](https://react-aria.adobe.com/Table). React Aria provides collection semantics, keyboard navigation, row headers, selection, and sorting, while Stand uses CSS Grid to support table, split, and stacked layouts at its responsive breakpoints.

## When to use

- To compare structured data across consistent columns.
- When rows need richer content than a conventional table layout can accommodate.
- When the same data must reflow into split or stacked layouts on narrower screens.

Do not use Table for a general page layout or a list with no meaningful column relationships.

## Peer dependencies

- `@emotion/react`
- `react`
- `react-dom`
- `react-aria-components`
- `typescript`

See the `peerDependencies` section of `package.json` for compatible versions.

## Example usage

<SandboxReact componentName={componentName} componentTsx={componentTsx} />

```tsx
import {
	Table,
	TableBody,
	TableCell,
	TableColumnHeader,
	TableHeader,
	TableRow,
} from '@guardian/stand/Table';

<Table
	aria-label="People"
	columns={{
		sm: '1fr',
		md: '1fr auto',
		lg: 'minmax(160px, 2fr) 1fr auto',
	}}
>
	<TableHeader>
		<TableColumnHeader isRowHeader>Name</TableColumnHeader>
		<TableColumnHeader>Team</TableColumnHeader>
		<TableColumnHeader>Status</TableColumnHeader>
	</TableHeader>
	<TableBody>
		<TableRow id="alex-smith">
			<TableCell>Alex Smith</TableCell>
			<TableCell compactLabel="Team: ">Editorial tools</TableCell>
			<TableCell compactLabel="Status: ">Active</TableCell>
		</TableRow>
	</TableBody>
</Table>;
```

Give every table an accessible name with `aria-label` or `aria-labelledby`. Keep cells in the same DOM order as their column headers, even when responsive placement changes their visual position. Set `isRowHeader` on the `TableColumnHeader` that identifies each row.

## Table Props

| Name                | Type                                     | Required | Default | Description                                                |
| ------------------- | ---------------------------------------- | -------- | ------- | ---------------------------------------------------------- |
| `children`          | `ReactNode`                              | No       | N/A     | Header and body composition.                               |
| `columns`           | `Partial<Record<Breakpoint, string>>`    | Yes      | N/A     | CSS Grid tracks by breakpoint. Values cascade upward.      |
| `headerVisibleFrom` | `'sm' \| 'md' \| 'lg'`                   | No       | `'lg'`  | Breakpoint at which the visible column header is restored. |
| `aria-label`        | `string`                                 | No       | N/A     | Accessible name when `aria-labelledby` is not used.        |
| `theme`             | `TableTheme`                             | No       | N/A     | Deeply partial override of generated Table design tokens.  |
| `cssOverrides`      | `SerializedStyles \| SerializedStyles[]` | No       | N/A     | Emotion styles applied after the component's base styles.  |

Table also accepts React Aria `TableProps`, including selection, sorting, row actions, and drag-and-drop hooks.

## TableCell Props

| Name           | Type                                     | Required | Default | Description                                                         |
| -------------- | ---------------------------------------- | -------- | ------- | ------------------------------------------------------------------- |
| `children`     | `ReactNode`                              | No       | N/A     | Cell content.                                                       |
| `compactLabel` | `ReactNode`                              | No       | N/A     | Visual label shown while the real column header is visually hidden. |
| `gridColumn`   | `Partial<Record<Breakpoint, string>>`    | No       | N/A     | Responsive CSS `grid-column` placement.                             |
| `gridRow`      | `Partial<Record<Breakpoint, string>>`    | No       | N/A     | Responsive CSS `grid-row` placement.                                |
| `theme`        | `TableTheme`                             | No       | N/A     | Deeply partial local token override.                                |
| `cssOverrides` | `SerializedStyles \| SerializedStyles[]` | No       | N/A     | Emotion styles applied after the component's base styles.           |

`TableHeader`, `TableBody`, `TableRow`, and `TableColumnHeader` expose their corresponding React Aria props, plus Stand theme and CSS override props.

## Customisation

Use `columns` for shared breakpoint track definitions and `gridColumn` or `gridRow` for cell placement. Use `theme` for visual customization and `cssOverrides` for content-specific alignment or grid areas.

The component intentionally does not prescribe a data model, column count, or cell content. Existing Stand components can be composed inside any cell.

Column resizing and virtualization should not be combined with responsive grid layouts without additional testing because they apply their own layout behavior.

## Custom Component Build

Table relies on React Aria for its collection and interaction behavior. Generated token variables are available from `@guardian/stand/component/table.css`, but a non-React implementation must provide its own table semantics, keyboard behavior, and responsive layout.
