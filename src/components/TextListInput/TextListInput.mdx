## Customisation

We recommend using the TextListInput component as provided, but it can be customised using the `theme` or `cssOverrides` props as required.

### Custom theme

The `theme` prop allows you to override specific design tokens for the TextListInput component:

<Canvas layout="padded" of={CustomTheme} />

```tsx
import type { TextListInputTheme } from '@guardian/stand/TextListInput';
import { TextListInput } from '@guardian/stand/TextListInput';
import { baseColors, baseSizing } from '@guardian/stand';

const customTheme: TextListInputTheme = {
	color: {
		blue: {
			background: baseColors.coolPurple[700],
			text: baseColors.orange[300],
		},
	},
};

const Component = () => <TextListInput letter="C" theme={customTheme} />;
```

### CSS overrides

The `cssOverrides` prop allows you to pass custom CSS to the TextListInput component, if the theme prop is not sufficient:

<Canvas layout="padded" of={CssOverrides} />

```tsx
import { TextListInput } from '@guardian/stand/TextListInput';
import { baseColors, baseSizing, baseSpacing } from '@guardian/stand';
import { css } from '@emotion/react';

const customStyles = css`
	border: ${baseSizing.size2Rem} solid ${baseColors.red[500]};
	background-color: ${baseColors.orange[700]};
	color: ${baseColors.warmPurple[300]};
	border-radius: ${baseRadius.corner4Px};
`;

const Component = () => (
	<TextListInput letter="O" cssOverrides={customStyles} />
);
```

## Custom Component Build

If you're not using React/Emotion, or `@guardian/stand` is not compatible with your project, you can create a custom TextListInput component using the styles defined in the `TextListInputTheme` type.

You will however be responsible for any additional functionality on top of the styles, for example image loading, image fallback, accessibility etc.

**`css`**

You can import the TextListInput styles as CSS from the package, make sure that your build process supports importing CSS from `node_modules`/`package.json`:
