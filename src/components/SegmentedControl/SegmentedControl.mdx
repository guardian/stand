# SegmentedControl

A connected, horizontal segmented control built on [React Aria ToggleButtonGroup and ToggleButton](https://react-aria.adobe.com/ToggleButtonGroup).
The public name follows the design terminology; React Aria's toggle buttons are the underlying implementation.
It supports a single selected option, with controlled or uncontrolled selection.
The default appearance matches Figma's Small / Condensed variant: 32px-high segments,
12px regular-weight Open Sans Compact labels and a blue selected fill and border.
Selecting an item does not change its label weight or width.

## When to use

- To choose between a small number of related options, such as view modes, display density or time periods.
- Use Tabs instead when each choice opens an associated content panel, or RadioGroup for a radio-style form field.

## Peer dependencies

- `@emotion/react`
- `react`
- `react-dom`
- `react-aria-components`
- `typescript`

See the `peerDependencies` section of `package.json` for compatible versions.
CSS-only consumers do not need these peers.

Load Open Sans using the [Getting Started font guidance](?path=/docs/getting-started--docs).

## Example usage

<SandboxReact componentName={componentName} componentTsx={componentTsx} />

```tsx
import {
	SegmentedControl,
	SegmentedControlItem,
} from '@guardian/stand/SegmentedControl';

<SegmentedControl
	aria-label="View mode"
	defaultSelectedKeys={['board']}
	disallowEmptySelection
	onSelectionChange={(keys) => console.log([...keys])}
>
	<SegmentedControlItem id="list">List</SegmentedControlItem>
	<SegmentedControlItem id="grid">Grid</SegmentedControlItem>
	<SegmentedControlItem id="gallery">Gallery</SegmentedControlItem>
	<SegmentedControlItem id="board">Board</SegmentedControlItem>
</SegmentedControl>;
```

Supply an accessible group name using `aria-label`, or `aria-labelledby` pointing to a visible label.
Each `SegmentedControlItem` needs a unique string or number `id`; the visible label does not determine its value.
Keep item labels stable when selected so assistive technology can announce selection.

## Props

| Name                             | Type                                       | Required    | Default | Description                                                                                |
| -------------------------------- | ------------------------------------------ | ----------- | ------- | ------------------------------------------------------------------------------------------ |
| `aria-label` / `aria-labelledby` | `string`                                   | Conditional | N/A     | Provide one to name the group.                                                             |
| `children`                       | `ReactNode` or render function             | Yes         | N/A     | `SegmentedControlItem` items, optionally inside a fragment.                                |
| `selectedKeys`                   | `Iterable<Key>`                            | No          | N/A     | Controlled selection, containing at most one item id.                                      |
| `defaultSelectedKeys`            | `Iterable<Key>`                            | No          | Empty   | Initial uncontrolled selection, containing at most one item id.                            |
| `onSelectionChange`              | `(keys: Set<Key>) => void`                 | No          | N/A     | Called with the selected ids, or an empty set when cleared.                                |
| `disallowEmptySelection`         | `boolean`                                  | No          | `false` | Prevents clearing the current selection. Initialise a selection when a choice is required. |
| `isDisabled`                     | `boolean`                                  | No          | `false` | Disables every item.                                                                       |
| `theme`                          | `SegmentedControlTheme`                    | No          | N/A     | Token overrides inherited by items.                                                        |
| `cssOverrides`                   | `SerializedStyles` or `SerializedStyles[]` | No          | N/A     | Styles applied to the group.                                                               |
| `className`                      | `string` or render function                | No          | N/A     | Class name applied to the group.                                                           |

Selection is always single and orientation is always horizontal; Stand does not expose `selectionMode` or `orientation`.
Other props and render functions follow the [React Aria ToggleButtonGroup API](https://react-aria.adobe.com/ToggleButtonGroup#api).
React Aria's single-selection mode exposes a `radiogroup` with `radio` semantics on native buttons, not radio inputs. Stand preserves these semantics.
Arrow keys move focus between enabled items; Space or Enter selects the focused item.

### SegmentedControlItem props

| Name           | Type                                       | Required | Default | Description                                                      |
| -------------- | ------------------------------------------ | -------- | ------- | ---------------------------------------------------------------- |
| `id`           | `string` or `number`                       | Yes      | N/A     | Selection identifier within the group.                           |
| `children`     | `ReactNode` or render function             | Yes      | N/A     | Visible label. For icon-only content, also provide `aria-label`. |
| `isDisabled`   | `boolean`                                  | No       | `false` | Disables this item.                                              |
| `theme`        | `SegmentedControlTheme`                    | No       | N/A     | Overrides inherited group tokens for this item.                  |
| `cssOverrides` | `SerializedStyles` or `SerializedStyles[]` | No       | N/A     | Styles applied to this item.                                     |
| `className`    | `string` or render function                | No       | N/A     | Class name applied to this item.                                 |

Use these items within `SegmentedControl`; selection is managed by the group, not item-level `isSelected`, `defaultSelected` or `onChange` props.
Other interaction props follow the [React Aria ToggleButton API](https://react-aria.adobe.com/ToggleButton#api).

## Customisation

### Custom theme

Group token overrides are inherited by all items. Item-level overrides take precedence.
The defaults use Stand semantic tokens for the design's neutral and selected colours.

<Canvas layout="padded" of={CustomTheme} />

```tsx
import { semanticColors } from '@guardian/stand';
import type { SegmentedControlTheme } from '@guardian/stand/SegmentedControl';

const theme: SegmentedControlTheme = {
	item: {
		selected: {
			backgroundColor: semanticColors.fill.greenWeak,
			borderColor: semanticColors.border.success,
			color: semanticColors.text.green,
		},
	},
};
```
