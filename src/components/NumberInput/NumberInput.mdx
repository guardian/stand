# NumberInput

A numeric input built on [React Aria NumberField](https://react-aria.adobe.com/NumberField), styled for Stand. Users can type a value or adjust it with decrement and increment buttons.

Both sizes have a maximum width of 190px and shrink to fit narrower containers. Use `fluid` to fill the available width instead.

## When to use

- For quantities, counts or measurements where increasing and decreasing a value is useful.
- For numeric values with optional minimum, maximum, step or locale-aware formatting.
- Use TextInput instead for identifiers such as telephone numbers or postcodes, where numeric arithmetic is not meaningful.

## Peer dependencies

- `@emotion/react`
- `react`
- `react-dom`
- `react-aria-components`
- `typescript`

See `peerDependencies` in `package.json` for compatible versions. Load the [Material Symbols font](?path=/docs/stand-tools-design-system-components-icon--docs) for the stepper icons.

CSS-only consumers do not need React or Emotion.

## Example usage

	flowColumn
	componentName={componentName}
	componentTsx={componentTsx}
/>

```tsx
import { NumberInput } from '@guardian/stand/NumberInput';
import type {
	NumberInputProps,
	NumberInputTheme,
} from '@guardian/stand/NumberInput';

<NumberInput
	label="Quantity"
	description="Choose a quantity between 0 and 10."
	defaultValue={4}
	minValue={0}
	maxValue={10}
/>;
```

Use `value` and `onChange` for a controlled input. React Aria commits typed values on blur or stepping, applies bounds and snaps to the nearest step. Clearing the field reports `NaN`; check `Number.isNaN(value)` rather than treating an empty field as zero. Characters that cannot form a number in the current locale are rejected by React Aria.

Arrow Up and Arrow Down adjust the value. Home and End move to the configured minimum and maximum. Formatting and parsing follow the locale; use React Aria's `I18nProvider` to set a specific locale.

## Customisation

Use `theme` for the numeric control and `formInputContainerTheme` for its label, description and wrapper. For example, the Custom theme story sets `theme={{ shared: { borderRadius: '0' } }}`.

Use `cssOverrides` for layout adjustments:

```tsx
import { css } from '@emotion/react';
import { NumberInput } from '@guardian/stand/NumberInput';

<NumberInput
	label="Quantity"
	cssOverrides={css`
		max-width: 10rem;
	`}
/>;
```

## Custom Component Build

The CSS and JavaScript token exports support custom implementations without React or Emotion. These examples demonstrate styling, not an equivalent replacement for React Aria's accessibility, validation and locale-aware interactions. The CSS-only example's stepper buttons are visual only; the JavaScript example uses native `stepDown()` and `stepUp()`.
