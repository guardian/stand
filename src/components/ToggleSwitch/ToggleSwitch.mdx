# ToggleSwitch

A switch component built on [React Aria](https://react-aria.adobe.com/Switch). It supports small and medium sizes, selected and disabled states, and an optional inline label.

## When to use

- To let users turn a single setting on or off immediately
- To represent a binary preference where the current state is visible

## Peer dependencies

- `@emotion/react`
- `react`
- `react-dom`
- `react-aria-components`
- `typescript`

See the `peerDependencies` section of `package.json` for compatible versions.

See [custom component build](#custom-component-build) for usage without React/Emotion.

```tsx
const Example = () => (
	<ToggleSwitch description="App has an access to your camera" defaultSelected>

	</ToggleSwitch>
);
```

## Props

See [React Aria `Switch` props](https://react-aria.adobe.com/Switch#api) for the full API, plus the additional props listed below.

| Name              | Type                                       | Required | Default | Description                                        |
| ----------------- | ------------------------------------------ | -------- | ------- | -------------------------------------------------- |
| `children`        | `React.ReactNode`                          | No       | N/A     | Label content rendered beside the switch.          |
| `description`     | `React.ReactNode`                          | No       | N/A     | Supporting text rendered below the label.          |
| `size`            | `'md'` \| `'sm'`                           | No       | `'md'`  | Controls the switch and label size.                |
| `isSelected`      | `boolean`                                  | No       | N/A     | Controlled selected state.                         |
| `defaultSelected` | `boolean`                                  | No       | N/A     | Default selected state for uncontrolled use.       |
| `isDisabled`      | `boolean`                                  | No       | `false` | Disables interaction and applies disabled styling. |
| `theme`           | `ToggleSwitchTheme` (partial)              | No       | N/A     | Override Stand tokens for this instance.           |
| `cssOverrides`    | `SerializedStyles` \| `SerializedStyles[]` | No       | N/A     | Low-level Emotion override.                        |
| `...props`        | `React Aria Switch` props                  | No       | N/A     | Other props such as `onChange` and `autoFocus`.    |

## Customisation

Use the `theme` prop to override ToggleSwitch tokens, or `cssOverrides` for low-level Emotion overrides.
