# `@guardian/stand` - Sharable non-Design System Components

**Stand contains two collections:** the **Tools Design System**, our core foundations and UI components, and **Sharable non-Design System Components**, reusable components that sit outside the design system. Both are available through `@guardian/stand`; inclusion in Stand does not imply design-system membership or verification.

This collection contains components intended to be reused across multiple Guardian tools without being part of the core design system, such as Byline, TagPicker, and PickerIframeModal.

Components here may follow the [Tools Design System](?path=/docs/stand-tools-design-system-introduction--docs) guidelines, but are not required to follow all of them or be verified by the design-system team. This is different from a design-system component that is awaiting verification.

Using design tokens or composing design-system components does not automatically make a component part of the Tools Design System.

All components are built with TypeScript, React, and Emotion, and are API-agnostic, they expose props so that consumers can wire in their own data and behaviour.

Focus on components that could be reused across multiple (2+) Guardian tools, and shared utility functions, hooks, or methods if they directly support such components. Components should not directly interact with external systems or APIs; they should remain as self-contained and reusable as possible. Instead expose props or hooks that allow consumers to integrate with external systems as needed.

If you're unsure where a new component belongs, start in this collection and flag it for discussion. See the [component placement guide](?path=/docs/contributing--docs#choosing-a-collection).
